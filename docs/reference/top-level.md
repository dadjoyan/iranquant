# Top-level API

The `iranquant` package re-exports the synchronous helpers, the
`AsyncIranQuant` client, the `IranQuant` facade, exceptions, models and quant
functions.

```python
import iranquant as iq

iq.history("فولاد")
iq.AsyncIranQuant()
iq.IranQuant()
iq.MarketScreener
iq.MarketWatcher
```
